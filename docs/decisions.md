## そのほか実装で決めたこと
- **シリーズCの名前を「お迎えから10年」から「きみとの時間」に変えた。** 時系列ではなくなったため。アカウント名に「10年」を使う場合は戻してもよい
- **1枚の文字は60px（1枚目は66px）。** 1行15字×2行＝30字が、左右の余白64pxの中に収まる大きさ。設計書どおり Y=500〜900 に置く
- **イラストは横960px。** 右端に並ぶ TikTok のボタンに掛からない幅。縁をぼかして紙になじませる
- **絵の使い回しは1話4回まで。** 同じ瞬間が2枚続く場面（見本の10〜11枚目など）だけ。これで費用が約2割下がる
- **フォント: Klee One SemiBold**（OFL・商用可）。代わりに Zen Kurenaido も同梱
- **台本の生成は Claude Opus 5**（1本 約25円）。Claude Code との会話で書けば0円。どちらの台本も同じ機械チェックを通す

## 2026-09-27 1本目（雨の日の散歩）を実画像で作って決めたこと
- **主役犬はまるの写真を元にした子**（本人指示）。成犬は設定画の候補B。以後の全コマは `assets/ref/dog_<年齢>.png` を参照する。まるの写真は非公開（`assets/ref/maru/` は git 管理外）。服は描かず水色の首輪だけ
- **背景色を #F2F1EE → #F5EFE4 に変更。** 生成画像の紙の色（実測の中央値）がこれで、#F2F1EE のままだとイラストの周りに黄色い四角が浮いた。さらに合成時にイラストの縁の色を背景色へ自動でそろえる（`compose.match_paper`）
- **レイアウト: 文字の中心 Y=600、イラストは Y=760 から横1040px。** 設計書の Y=500〜900・横1000 より少し上・大きく。下の余白は TikTok のキャプション欄に空ける
- 紙の粒子は 0.06（強いと灰色っぽくなる）
- 小物の色もコマをまたいでそろえる（リードは水色）。1枚目で茶色のリードが出たので作り直した
- 別れの予感のコマ（16〜17枚目）に、窓の映り込みで「もう1匹の犬」が出た → 死を連想させるので作り直し。**このコマでは映り込み・幽霊のような表現を禁止する**
- **1枚目は絵本の表紙**（本人指示）: 上にアカウント名とシリーズ名を小さく、その下にフックの一文（「〜の理由」「なぜ」「◯時」）、絵には必ず犬。`rules.yaml` の cover_dog / cover_hook_words でチェックする
- **絵の使い回しは禁止**（本人指示: 16・17枚目が同じ絵で気になった）。max_reuse=0。1本あたり +8円ほど
- **2026-09-28 スライドを 9:16 → 3:4（1080×1440）に変更。** 1本目の実機画面で、TikTok のフォトモードは 9:16 の画像の上下を切って約3:4の枠に表示していた。3:4 で作れば切れず、文字と絵が大きくなる。YouTube 用の動画は 9:16 のまま、スライドの上下を紙の色で埋める

## 2026-09-29 1日3本・連載化・文と絵のチェック
- **当面（2週間の試験）は1日3本**: 朝7時＝犬が語る「きみからのお願い」、昼12時＝「ふつうの一日」、夜21時＝泣ける本編（C・E・Bの重め）。2週間でフォロワー+100に届かなければ1日1本に戻す
- **フォローする理由を作る**: 表紙に「第N話」、20枚目の下に「つぎのお話 ◯月◯日 朝7時『タイトル』」、キャプションに「毎日 朝7時・昼12時・夜21時に、この子の絵本を1話ずつ。」（`schedule.py` が投稿順から話数と次回を計算）
- **文と絵のずれを機械で見る**: `./ehon qa <回> --fix`。gpt-5-mini に画像と文を見せ、犬の体の向き・視線の先に誰がいるか・人の位置を先に言わせてから判定する（奥行きの「後ろ」と犬にとっての「後ろ」を混同させない）。3本目12枚目「振り返ると、ちゃんとあなたがいる」なのに飼い主が前を歩いていたのを本人が指摘 → この判定で検出できることを確認。1本あたり約2円
- 台本の絵の指示には、文が表す位置関係・視線・動作を必ず英語で明記する（台本プロンプトに追加）
- 書き出しフォルダ名は `日付_時刻_ID`（例 2026-10-01_0700_A02）
