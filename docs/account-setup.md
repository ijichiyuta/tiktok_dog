# アカウント開設の手順（匿名・顔なし）

アカウントは本人しか作れない（電話番号の確認があるため）。この手順どおりに進めれば、身元につながる経路を塞いだ状態で開設できる。
**最優先は「知り合いかも」経由で身バレしないこと。** 勤務先の同僚の連絡先に、アカウントがおすすめとして出る経路を全部切る。

## 0. 先に決めること
- アカウント名とユーザー名（[account-names.md](account-names.md)）
- アイコン: 設定画を確定したあとに `./ehon brand icon --n 3` で候補を作る（1枚 約4.5円）
- 自己紹介文（下の案）

## 1. 専用の Google アカウント（YouTube と TikTok の登録に使う）
1. シークレットウィンドウで新しい Gmail を作る。姓名の欄にはブランド名を入れ、本名は入れない
2. 電話番号の確認は本人の番号でよい（公開されない）。**再設定用のメールには本業のアドレスを使わない**
3. 2段階認証をオンにする

## 2. YouTube チャンネル
1. 1のアカウントで YouTube にログイン →「チャンネルを作成」→ 名前とハンドル（@ユーザー名）を入れる
2. YouTube Studio → カスタマイズ
   - プロフィール写真: アイコン
   - バナー: `./ehon brand banner`（2560×1440。文字は入れない）
   - 説明: 自己紹介文＋「イラストはAIで生成しています」
3. 設定 → アップロード動画のデフォルト設定
   - カテゴリ: ペットと動物
   - 視聴者: 「いいえ、子ども向けではありません」
   - 言語: 日本語
4. 設定 → チャンネル → 国: 日本
5. 電話番号の確認（studio の「機能の利用資格」）を済ませる（予約投稿に必要な場合がある）

### YouTube API の監査（自動アップロードを使うとき）
監査が通るまでは、API で上げた動画が非公開のまま固定される。それまでは Studio で手動予約する。
1. Google Cloud で新しいプロジェクトを作る → 「YouTube Data API v3」を有効にする
2. OAuth 同意画面: 外部・テスト。テストユーザーに1のアカウントを追加する
3. 認証情報 →「OAuth クライアント ID」→ 種類「デスクトップ アプリ」→ JSON をダウンロード → `.secrets/client_secret.json` に置く
4. `./ehon youtube auth` → ブラウザで1のアカウントを選んで許可
5. 監査の申請: https://support.google.com/youtube/contact/yt_api_form （用途: 自作の動画を自分のチャンネルに予約投稿するための個人用ツール）
6. 通ったら `config/channel.yaml` の `youtube.audited` を `true` にする

## 3. TikTok
1. スマホの TikTok で「新規登録」→ **電話番号ではなく、1の Gmail で登録する**（電話番号で登録すると、連絡先経由でおすすめに出やすくなる）
2. 名前（表示名）・ユーザー名・自己紹介・アイコンを設定する
3. **アカウントの種類は「個人アカウント」のまま**にする
   - ビジネスアカウントにすると、使える曲が商用ライブラリだけになる
   - PR 投稿を始める段階で、あらためて見直す
4. **設定とプライバシー → プライバシー →「アカウントをおすすめに表示」→ 全部オフ**
   - 連絡先／Facebook の友達／共通のつながりがある人／リンクを開いた人・送信した人
5. 設定 → 「連絡先と Facebook の友達を同期」→ オフ（同期しない）
6. プライバシー →「アクティビティのステータス」→ オフ
7. 同じ端末で本アカウントと切り替える場合、**投稿前に今どちらのアカウントにいるかを必ず確認する**

### 毎回の投稿（./ehon export の「投稿メモ.txt」と同じ）
1. iPhone の「ファイル」→ iCloud Drive → ehon → その日のフォルダ → 20枚を選ぶ →「画像を保存」
2. TikTok →「＋」→ 写真 → 01〜20を順番に選ぶ（フォトモード）
3. 音楽: 商用利用できるピアノ曲。シリーズごとに1曲に固定する
4. キャプション: caption.txt を貼る
5. その他の設定 →「AI生成コンテンツ」をオン。位置情報は付けない
6. 21:00〜23:00 に投稿する（TikTok Studio の予約投稿が写真投稿にも使えるかは未確認。使えれば週1回まとめて予約する）

### 固定投稿（3本）
1. 代表作（最初の2週間で保存率が一番高かった回）
2. 犬目線シリーズ（A）の第1話
3. 「みんなの子の話」の募集告知（フォロワー1,000人を超えてから）

## 3'. 既存のアカウントを転生させる場合（2026-09-26 検討: @boku_mo_tanoshi）
元は「おじさん【スマブラ切り抜き】」。投稿0本・フォロワー60・フォロー64・いいね0。

**使ってよい条件（全部満たすこと）**
1. BS（BACKSTAGE）の業務のために作ったアカウントではない。契約6条では、業務で使うSNSアカウントはBSに帰属する
2. 本人の電話番号・連絡先経由でつながった知り合いが、フォロワーにいない
3. 登録メールを専用の Gmail に切り替えられる（設定 → アカウント → アカウント情報）

**転生の手順**
1. フォロワー60人を確認し、知り合いはフォロワーから削除する（プロフィール → フォロワー → 「…」→ 削除）
2. フォロー中の64件を全部外す（スマブラや占いなど、犬と関係のないジャンルの興味の信号を消す）
3. いいね・お気に入りを非公開にする。視聴履歴を消し、「おすすめフィードを更新」を実行する（設定 → コンテンツの設定）
4. 3〜5日間、犬・絵本系の投稿を見て、保存し、10件ほどフォローする（おすすめの中身を犬ジャンルに寄せる）
5. 表示名・ユーザー名・アイコン・自己紹介を変える（ユーザー名は30日に1回、表示名は7日に1回しか変えられない）
6. 上の「3. TikTok」の4〜6（おすすめに表示を全部オフ・連絡先の同期をオフ）を実施する
7. 最初の3本を投稿する

## 4. 自己紹介文の案（名前が決まったら差し替える）
- ことばのかわりに版: 「犬は、ことばのかわりに そばにいる。この子の気持ちを、絵本にしています。毎晩21時。#AI作画」
- おかえりの絵本版: 「なんでもない一日の、おかえりまで。犬と暮らす毎日を絵本にしています。毎晩21時。#AI作画」
- きみと10年版: 「10年しかない、この子との"ふつうの一日"を絵本にしています。毎晩21時更新。#AI作画」（設計書のまま）

## 5. やってはいけないこと
- まるの実写、自宅・散歩コース・名古屋が分かるもの（窓の外の景色、地域のハッシュタグ）
- 本名・勤務先・本業の話
- 本アカウントからのいいね・フォロー（アクティビティ経由でつながりが見える）
- 物語の投稿に商品リンクを載せる（紹介は別の投稿にして #PR を付ける）

## 6. お金まわり（収益化の前に）
- 副業の所得は確定申告し、**住民税は「自分で納付（普通徴収）」を選ぶ**。給与天引きのままだと、会社に住民税額の変化で知られる可能性がある
- 自社商品（うちの子絵本）を売る段階で、特定商取引法の表記（氏名・住所・電話番号）が必要になる。「請求があれば遅滞なく開示」の書き方や、販売プラットフォーム側の表記を使う方法を、その時点で検討する
