# アカウント名の候補（2026-09-25）

## 結論

**第一候補は「ことばのかわりに｜犬の気持ちの絵本」。**

- 感動の仕組みの3番目「無言の献身」をそのまま名前にしている。犬は言葉で言えないので、その気持ちを代わりに絵本にする、という意味になる
- 5つのシリーズのどれにも合う。犬目線の回（A）なら犬の手紙、飼い主目線の回（B・C・E）なら行動の意味の翻訳になる
- 寿命の数字や別れの語を含まないので、ペットロス中の人（ペルソナ7）や、10歳を過ぎた子の飼い主（ペルソナ4・5）を刺さない
- 将来の自社商品に名前のまま使える（「ことばのかわりに — うちの子絵本」「言えなかったありがとうを絵本に」）
- 「｜」から後ろ（検索語の部分）は、あとで自由に変えられる

次点は **「おかえりの絵本」** と **「きみと10年｜マルプーの絵本」**。比べた結果は下の表。

## 判断の基準

| # | 基準 | 理由 |
|---|---|---|
| 1 | 何のアカウントか一目でわかる | TikTok の検索は表示名とプロフィール文を拾う。「犬」「絵本」「マルプー」「犬の気持ち」のどれかを「｜」の後ろに入れる |
| 2 | 泣ける理由が名前ににじむ | 設計書の5つの仕組み（視点の反転・時間の非対称・無言の献身・別れの予告・決意）のどれか |
| 3 | ペットロス層を刺さない | 「虹」「天国」「さよなら」、寿命の数字は、見た瞬間に閉じられる人がいる |
| 4 | 商品に伸ばせる | 6か月目以降の「うちの子絵本」受注・LINEスタンプ・他犬種展開に、名前を変えずに使えるか |
| 5 | 短く、ひらがな中心 | ペルソナ10（67歳）が読める。アイコンの横で切れない（TikTok の表示名は30字まで） |
| 6 | 既存と紛らわしくない | 下の「重複チェック」 |

**TikTok の仕組み上の注意**: 表示名は何度でも変えられるが、ユーザー名（@の後ろ）は30日に1回しか変えられない。ユーザー名はブランド名だけにし、検索語は表示名の「｜」の後ろに置く。

## ユーザー名（@の後ろ）の案
英数字・「_」・「.」のみ。TikTok と YouTube でそろえる。
- ことばのかわりに → `@kotoba_no_kawari` / `@kotobanokawarini`
- おかえりの絵本 → `@okaeri_ehon`
- きみと10年 → `@kimito10nen`
- だまって、そばに → `@damatte_sobani`

## 重複チェック（2026-09-25 時点）
- YouTube と TikTok をログインせずに検索した（docs/research-2026-09-25.md §8）。そのほか Web 検索もした
- 「ことばのかわりに」「おかえりの絵本」「だまって、そばに」「きみと10年」「この子のぜんぶ」は、完全一致で目立つアカウントが見つからなかった
- **Instagram と、TikTok アプリ内でユーザー名が取れるかは未確認。** 開設するときにアプリで確かめること
- 参考: 「うちの子絵本」の競合として、Instagram に「Paws&Booktails 世界に1冊の愛犬絵本」がある（写真を水彩風にして絵本にするサービス）→ 6か月目の商品設計で調べる

## 決め方の提案
上位3案（ことばのかわりに／おかえりの絵本／きみと10年）でアイコンを作って並べ、1日寝かせてから決める。
名前が決まったら `config/channel.yaml` の `name` と `handle` を書き換える。
