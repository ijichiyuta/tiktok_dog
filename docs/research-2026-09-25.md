## 1. 画像生成の単価

- OpenAI `gpt-image-2.5-flare`（スナップショット `gpt-image-2.5-flare-2026-09-08`）。精密編集向けの `gpt-image-2.5-sunburst` もある
  - 料金はトークン課金。画像出力 $30/M、画像入力 $8/M、テキスト入力 $5/M。**Batch API は 50%引き**
  - 1536×1024 の1枚あたり: low $0.0047 / **medium $0.0103** / high $0.041（出力分のみ。参照画像の入力トークンは別）
  - `/v1/images/edits` は参照画像を最大16枚まで受け付ける
  - 出典: https://developers.openai.com/api/docs/pricing ・ https://developers.openai.com/api/docs/models/gpt-image-2.5-flare
- **実測値（nariagari・2026-09-19）**: 参照なし 2.44円、参照1枚 4.3円、参照2枚 6.2円
- Gemini `gemini-3.1-flash-lite-image` は $0.0336/枚（Batch で半額）。画像出力に API の無料枠はない
- FLUX.1 Kontext pro は $0.04/枚、FLUX.2 pro は約 $0.047/枚

→ **gpt-image-2.5-flare の medium を採用する。** 20枚 × 参照1枚 × 30本 ≒ 月2,600円。使い回しや人物だけのコマで下がる。Batch を使えばさらに半額（将来の選択肢）。

## 3. YouTube Data API
- ⚠️ **2020年7月28日以降に作られた未監査の API プロジェクトから `videos.insert` でアップロードした動画は、非公開に固定される。** 解除には監査が必要で、申請先は https://support.google.com/youtube/contact/yt_api_form
  - → 監査が通るまでは、書き出した動画を **YouTube Studio から手動で予約投稿**する（週1回・7本まとめて）
- `status.publishAt`（privacyStatus が private のときだけ設定可）で予約公開できる。`status.containsSyntheticMedia` で合成コンテンツを開示できる
- アップロードの割り当ては専用枠で 1日100回
- 出典: https://developers.google.com/youtube/v3/docs/videos/insert

## 4. ⚠️ YouTube の収益化ポリシー（inauthentic content・2025年7月15日に改定）
収益化できない例として、次のものが明記されている。
- "Image slideshows, templated storylines, or scrolling text with minimal or no narrative, commentary, or educational value"
- "AI-generated content made with generic or unoriginal templates giving the impression of mass production"
- "characters are put in the same situation over and over again with the same outcome"

許可される例: "a series following a set of characters across episodes … in which each video has a distinct storyline"

→ **毎回ちがう物語であることが生命線。** 同じ結末を繰り返さない（「いつか」→「今夜ぎゅっと」が毎回同じだと該当しうる）。YouTube 版は **読み聞かせのナレーション（VOICEVOX・無料）を付ける**と「narrative」の要件を満たしやすい。
出典: https://support.google.com/youtube/answer/1311392

## 5. TikTok Content Posting API
- 未監査のクライアントは **SELF_ONLY（自分だけ）でしか投稿できず、24時間で最大5ユーザー**まで
- 写真投稿は **PULL_FROM_URL のみ**（ドメインか URL プレフィックスの所有を証明する必要がある）。最大35枚、JPEG/WebP、最大1080p。`is_aigc` を付けると AI 生成ラベルが付く
- **`MEDIA_UPLOAD` モードなら写真も「下書き」として本人の受信箱に送れる**（BGM を選んで投稿を完成させるのは本人）→ 半自動の最終形はこれ
- 出典: https://developers.tiktok.com/doc/content-posting-api-reference-photo-post ・ https://developers.tiktok.com/doc/content-sharing-guidelines

## 6. ⚠️ TikTok Creator Rewards（再生報酬）
- 日本は対象国。ただし **「フォトモードを使用していないこと」が条件で、対象外の例に「スライド動画」が明記されている**
- 日本・韓国向けの規約（2025年4月版）では **フォロワー要件が5万人**
- 出典: https://www.tiktok.com/creator-academy/article/creator-rewards-program（2026-09-11 更新）

→ **設計書の「1万フォロワーで動画版の再生報酬」の段は成立しない。** 収益は最初から「アフィリエイト → 企業案件 → うちの子絵本（自社商品）」で組む。

## 7. AI 生成物のラベル
- TikTok: ラベルが必須なのは写実的な AI 生成物。イラストは必須ではないが、設計どおり毎回ラベルを付ける（API では `is_aigc`）
- YouTube: 開示が必要なのは写実的な改変・合成だけ。アニメや空想的な内容は不要
