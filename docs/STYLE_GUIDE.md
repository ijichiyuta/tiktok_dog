# 縦型トーク動画 デザインガイド（リファレンス分析）

リファレンス: Instagram リール「おすすめに載る新ルール」（1080×1920 / 29.97fps / 73.6秒）。
黒背景スタジオで話す人物に、テロップと図解を「1〜1.5秒ごとに切り替え続ける」タイプの編集です。
ここでは、そのセンスを数値とルールに落とし込んでいます。`reelfx` のプリセットはすべてこの分析に基づいています。

---

## 1. 全体の設計思想

| 要素 | ルール |
|---|---|
| 背景 | 真っ黒なスタジオ＋**紫ネオンの渦**（人物の背後だけ。輪郭の外側で光る） |
| 人物 | 画面中央。顔は y≈350〜650。**強いビネット**で周囲を落とし、スポットライトに見せる |
| テロップ位置 | 胸の前、**y=850〜1250 が主戦場**（顔は絶対に隠さない）。下段は y≈1500〜1750（図解・バー） |
| 情報密度 | 1画面に1メッセージ。**0.9〜1.5秒でテロップを切り替え**（最長でも2.5秒） |
| 切替テンポ | 入りは 0.2〜0.3秒、**出は 0.05〜0.1秒の即消し**（余韻を残さない） |
| 画面の静止 | 禁止。何かが常に動いている（ネオン、ゆっくりした拡大 drift、光沢のスイープ） |

## 2. 配色ルール（意味で色を決める）

| 色 | 用途 | 例 | reelfx スタイル |
|---|---|---|---|
| **白** | 地の文・つなぎ | まずインスタは / ちなみに | `white_gothic` |
| **オリーブゴールド（金属）** | 結論・キーワード・数字 | 優先ユーザー / 徹底解説 / 1 | `gold_mincho` `gold_gothic` |
| **シルバー（金属）** | 見出しの補助・前振り | Instagram / 新ルール / あなたの動画が | `silver_mincho` `silver_gothic` |
| **クリムゾン** | 警告・否定・危機 | ここからが重要 / 終わります / 誰に拡散するのか | `crimson_gothic` `brush_red` |
| **紫** | 抽象・AI・精度 | おすすめの精度が落ちて | `purple_gothic` |

- 金は単色ではなく**上が淡いクリーム → 中央に"水平線" → 下がオリーブ**の金属グラデ。これが「安っぽくない金」の正体。
- 金・銀には**上エッジの細いハイライト（ベベル）**と**右下に落ちる黒のぼかし影**（dx=5, dy=8, blur=7）。
- 1つのテロップに色は最大2色。強調したい語だけ色を変える（`{強調|1|gold_gothic}` 記法）。

## 3. タイポグラフィ

| 役割 | 書体 | 備考 |
|---|---|---|
| 見出し・結論 | 極太明朝（Zen Old Mincho Black） | 少し斜体（skew 0.1〜0.14）で勢いを出す |
| 通常テロップ | 極太ゴシック（Noto Sans JP 900） | 白＋濃いフチ＋柔らかい影 |
| 背景の巨大文字 | 明朝を太らせて輪郭を荒らした「筆文字風」 | 画面からはみ出すサイズ（450px超）、暗い赤、半透明 |
| 欧文 | 明朝の欧文を字間広め（tracking 0.12） | "Instagram" |

- **サイズのジャンプ率を極端に**。「{意|1.7}図的に」「{優先|1.45}ユーザー{です|0.4}」のように、1文字目だけ巨大にしたり語尾を 0.4 倍にしたりする。
- 行間は詰める（line_gap −0.05〜0.12）。見出しの2行目は小さく、字下げなし。

## 4. モーション語彙（reelfx の Anim 名）

| 演出 | 使いどころ | Anim |
|---|---|---|
| ポップ（弾んで出る） | 通常テロップの 8 割 | `pop()` |
| 叩きつけ＋白フラッシュ | 見出し・結論・数字 | `slam()` |
| 横ストリーク収束 | ボックス・ラベルの出現／吹き出しの退場 | `streak()` |
| 白ブロックのワイプ | まとめ・キーワードの提示 | `wipe()` |
| 横スライド＋ブラー | 見出しの2要素目 | `slide()` |
| 縦落下 | 縦書きタグ | `drop()` |
| ボケ→ピント | 背景の巨大文字・グループの退場 | `blur_in()` |
| 横伸び→縮む | 数字を含む主張 | `stretch()` |
| グリッチ＋RGBずれ | 場面転換・不安をあおる語 | `glitch()` `rgb_split()` |
| タイプライター | 引用・回想 | `typewriter()` |
| 光沢スイープ | 表示 0.3〜0.8 秒後に 1 回だけ | `shine()`（emph） |
| 揺れ | 警告 | `shake()`（emph）＋画面全体の `shake` |

**画面全体の FX**（`tl.fx`）: `glitch`（場面転換）、`flash`（稲妻・転換）、`hsmear`（横ブラーで次の話題へ）、`tint`（回想を青紫に）、`shake`、`rgb`、`zoom`、`vignette`。

## 5. 図解パーツ

- **積み上げボックス**: 新しい箱が一番上に入り、古い箱は下へ押し出される（紺 → マゼンタ → 金）。
- **2列グリッドの金ボックス**: 指標を並べ、最後に幅広の箱で締める。次の場面で 45% に縮小して下へ退避。
- **白枠＋中を金で満たすゲージ**／**リーチ数メーター**（100 / 300 / 500 / 1000 / 3000）。
- **緑のプログレスバー＋スマホ**（視聴維持率）。「閾値」は赤いタグ。
- **アバター＋ハート**（レコメンドの説明）: スマホから左右のユーザーへハートが飛ぶ → 3×3 グリッド → 枠で絞り込み → 黄色パネル → 黒金ボックス。
- **縦書き黒タグ**: 画面右端。上から落ちてくる。
- **CTA**: 金テロップ＋オレンジの指アイコンがタップ（放射線がはじける）。

## 6. サウンド

入りの種類ごとに効果音を必ず付ける（`sfx=`）: pop → `pop`、slam → `hit`、streak/slide → `whoosh`/`swish`、
グリッチ → `glitch`、稲妻 → `zap`、光沢 → `shine`、タイプ → `type`、タップ → `tap`。
効果音は声より 6〜10dB 下（`--sfx-gain 0.4〜0.6`）。

## 7. 冒頭 2.5 秒のテンプレ（一番センスが出る部分）

1. 0.0s ピンクのレンズストリーク
2. 0.1s 「今日」「Instagram」がグリッチで出現
3. 0.5s 背景に巨大な赤い筆文字「いきなり」がズームで出る
4. 0.55〜1.0s シアンの斬撃＋稲妻＋青白いフラッシュ
5. 0.9s 「おすすめ」が右から白熱した状態でスライドイン
6. 1.4s 「新ルール でしたね」が白ブロックのワイプで出る
7. 2.25〜2.45s 全体グリッチで本編へ

→ `recipes.opening()` 1 行で再現できます。
